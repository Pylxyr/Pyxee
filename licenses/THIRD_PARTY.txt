FFmpeg libraries (linked into Pyxee: libavformat, libavcodec, libswresample, libavutil)
  https://ffmpeg.org  and  https://github.com/FFmpeg/FFmpeg
  Version: n8.1.3, commit 1041abdc962f4cc4f394aa8de9dc5236c0c3b9e7
  License: GNU Lesser General Public License, version 2.1 or later (LGPL v2.1+).
  The full license text is in FFmpeg-LGPL-2.1.txt, which ships with Pyxee next to this file.

  This software uses libraries from the FFmpeg project under the LGPLv2.1. Pyxee uses a reduced build that only
  decodes audio, compiled without any GPL or non-free parts and linked statically. FFmpeg's code is not modified:
  the build takes the commit named above unchanged. Pyxee's own glue code (crates/audio/csrc/pxdec.c) only calls
  FFmpeg's public interfaces.

  Source, and how to replace the FFmpeg that Pyxee uses: Pyxee is MIT licensed and its source is public at
  https://github.com/Pylxyr/Pyxee. The FFmpeg commit, the exact configure options and the build steps are in
  scripts/build-ffmpeg.sh. To build Pyxee with a different or modified FFmpeg, change the commit (or the source
  tree) there and run `cargo xtask ffmpeg`, then build Pyxee again.

  FFmpeg is a trademark of Fabrice Bellard, originator of the FFmpeg project.


yt-dlp (bundled program; it runs as a separate process and Pyxee does not link it)
  https://github.com/yt-dlp/yt-dlp
  Version: 2026.10.21 (the yt-dlp.exe published with that release, bundled unmodified in the installers and the
  portable zip; Settings > Updates can later replace it with a newer upstream release on the user's machine).
  License: yt-dlp's own code is released under The Unlicense. The Windows yt-dlp.exe is a PyInstaller build, and
  upstream states that these executables include GPLv3+ licensed code, so the executable as a whole is a combined work
  licensed under the GNU General Public License, version 3 or later (https://www.gnu.org/licenses/gpl-3.0.html).
  Pyxee starts yt-dlp.exe only as a separate program (command line and standard streams) and does not link it or
  include its code; Pyxee's own source stays MIT licensed.
  The full GPL v3 text is in GPL-3.0.txt, and upstream's list of the licenses of everything bundled in its
  executables is in yt-dlp-THIRD_PARTY_LICENSES.txt. Both ship with Pyxee next to this file.

  Where to get the source code: the source of yt-dlp 2026.10.21, with the build recipe for the executable (bundle/ and
  bundle/requirements/), is published by its authors at
  https://github.com/yt-dlp/yt-dlp/archive/refs/tags/2026.10.21.tar.gz
  The third-party components that upstream's build bundles are the ones named in yt-dlp-THIRD_PARTY_LICENSES.txt.
  Pyxee does not change yt-dlp.exe; it is the file upstream published for that release.
