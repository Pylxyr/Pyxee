# Security policy

## Reporting a vulnerability
Please report security problems **privately**, using GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/Pylxyr/Pyxee/security) of this repository and choose **Report a vulnerability**.
Please do not open a public issue or pull request for a security problem.

Include what you found, the Pyxee version (Settings, About), the steps to reproduce it and what you think the impact is.
I will look at reports as soon as I can and tell you what I decide.

## What is covered
Pyxee itself: the application, its installer and portable zip, and its in-app updater. Problems in yt-dlp, FFmpeg or
other components Pyxee uses belong to those projects; please report them upstream (if Pyxee makes the problem worse, tell
me as well).

## Supported versions
Only the newest release gets fixes. Settings -> Updates installs it.

## Not security reports
Songs that do not load, "sign in to confirm you're not a bot" and similar problems are ordinary bugs: please use the
[issues](https://github.com/Pylxyr/Pyxee/issues).
